# Agents

## Purpose

This area is reserved for the SocAlytics intelligence-plane agent runtime and tooling.

## Planned Ownership

The planned boundary includes Hermes orchestration, Coach Agent and Specialist Agent runtime concerns, and the tooling that supports those agents within their approved authority.

## Exclusions

Platform APIs, client applications, Analyst Manager software, Analyst SDKs, and Analyst capability implementations do not belong here. This scaffold contains no services, agents, tools, packages, tests, manifests, containers, or product code.

## Current Status

This directory is non-executable. It currently records only a planned ownership boundary and does not provide build, test, package, runtime, or deployment support.
