# Tasks: Docker Desktop Runtime Adapter for Analyst Execution

**Input**: Design documents from `specs/20261015-092159-docker-runtime-adapter/`

**Prerequisites**: [plan.md](plan.md), [spec.md](spec.md), [research.md](research.md), [data-model.md](data-model.md), [contracts/analyst-container.md](contracts/analyst-container.md), [contracts/registry-credentials.md](contracts/registry-credentials.md), [contracts/workflow-capabilities.md](contracts/workflow-capabilities.md), [quickstart.md](quickstart.md)

**Tests**: Required by the constitution. Every task adds the tests for the code it creates in the same task, so both solutions build and their test suites stay green after each task.

**Organization**: Tasks are grouped by user story. Merged before this feature starts (do not re-create): Analyst Manager Work Execution (`IContainerRuntimeAdapter`, `AttemptLaunch`, `IAttemptExecution`, `RuntimeAdapterCatalog`, `PreflightRunner`, `PreflightScheduler`, `RuntimeCompatibilityList`, `AttemptRunner`, `HeartbeatLoop`, `AttemptRegistry`, `DrainCoordinator`, `WorkAcquisitionService`, `QueueCredentialProvider`, the simulated runtime, `FakePlatform`, the end-to-end harness), Analyst Registry (`ImageRegistryOptions`, `OciDistributionClient`, `RegistryWorkflowDefinitionResolver`, `OciRegistryContainerFixture`), Analysis Result Manifests and Validated Acceptance (`ResultPublisher`, result grants), Analysis Result Read for Jobs (`AttemptLaunch.InputsDirectory`, `UpstreamStager` with `AttemptsRoot` and `inputs/`), and the queue-credential endpoint pattern in `AnalystManagerSelfEndpoints.cs` and `IssueQueueCredentials.cs`. The `docker-desktop` entry of `runtime-compatibility.json` is not added by any task: a person adds it after manual Windows verification (quickstart.md § Windows).

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependencies on incomplete tasks); consecutive `[P]` tasks under one heading run in parallel, each from the same commit
- **[Story]**: Which user story this task belongs to (US1–US3)
- Every task names its exact file paths
