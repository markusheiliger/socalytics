# Contract: MCP Server Interface

The server's interface to the agent runtime (MCP over Streamable HTTP), to the orchestrator (health), and to the
platform (outbound calls), plus its image. Platform semantics are those of
[Agent Tools API](../../archive/20261018-104924-agent-evidence-tools/contracts/agent-tools-api.md); this contract adds none.
Values marked *profile* stay open in
[Production Deployment and Operations](../../../docs/architecture/production-operations.md#versioned-production-profile).

## 1. MCP endpoint (agent runtime → server)

| Item | Value |
| --- | --- |
| Transport | MCP Streamable HTTP, stateful sessions, JSON responses (no server-initiated streams) |
| Endpoint | `/mcp` on port 8080 (HTTP; TLS terminated outside the image, *profile*) |
| Authentication | `Authorization: Bearer <runtime secret>` on every request; otherwise `401`, no session |
| Binding (on `initialize`) | `SocAlytics-Attempt-Id: <uuid>`, `SocAlytics-Fencing-Token: <token>`; missing or malformed → `400` |
| Binding check | `readPinnedAgentArtifacts` for the attempt; `404` or `409 agent-attempt-stale` → the same status with the platform's problem body, no session |
| Later requests | `Mcp-Session-Id`; binding headers absent or equal, otherwise `400` and the session stays unchanged |
| Session end | `DELETE /mcp`, idle timeout, server stop |
| Session limit | Beyond `SOCALYTICS_MCP_MAX_SESSIONS` → `503` on `initialize` |
| Capabilities | `tools` (`listChanged: false`) only; resources, prompts, completions, logging, sampling, and elicitation are not offered |

### `tools/list`

Returns the tools of the session's policy (pinned tool policy ∩ catalog), in allowlist order, each as
`{ name: toolId, description, inputSchema, outputSchema }` from the generated catalog. The description states the
tool's answer kind and, for `analysis-unavailable` tools, the producing capability.

### `tools/call`

| Case | Result |
| --- | --- |
| Name not in the catalog | JSON-RPC error `-32602` (invalid params) |
| In the catalog, not in the session's policy | Tool error, `{ origin: "mcp-server", status: 403, problem: { type: "urn:socalytics:problem:agent-tool-not-permitted", … } }`; no platform request |
| Arguments invalid against `inputSchema` | Tool error, `{ origin: "mcp-server", status: 400, problem: { type: "urn:socalytics:problem:validation", errors: [{ pointer, detail }] } }`; no platform request |
| Platform `200` | `structuredContent` = platform body `{ callId, toolId, outcome, result }` unchanged; `content` = one text item with the same JSON |
| Platform non-`200` | Tool error, `{ origin: "platform", status, callId, problem }` with the platform's problem details unchanged (stale dispositions including `scope-lost`, `agent-tool-not-permitted`, not found, validation, `agent-tool-call-id-reused`, `agent-tool-call-limit-reached`, `evidence-storage-unavailable`) |
| No platform answer within the timeout, connection failure | Tool error, `{ origin: "mcp-server", status: 503, callId, problem: { type: "urn:socalytics:problem:mcp-platform-unavailable" } }` |
| Platform refuses the server's credentials twice | Tool error, `{ origin: "mcp-server", status: 502, callId, problem: { type: "urn:socalytics:problem:mcp-platform-authentication-failed" } }` |

Every forwarded call is exactly one platform request and is never retried; `callId` is generated by the server.

## 2. Health (orchestrator → server)

| Request | Response |
| --- | --- |
| `GET /alive` | `200 { "status": "alive" }` while the process serves requests |
| `GET /health` | `200 { "status": "ready" }` while a valid workload token is held or obtained; otherwise `503 { "status": "not-ready" }` |

Neither requires the runtime secret.

## 3. Outbound calls (server → platform)

Only these operations, at `SOCALYTICS_MCP_PLATFORM_URL`; proofs and the assertion audience use
`SOCALYTICS_MCP_PLATFORM_PUBLIC_BASE_URL`:

| Operation | Use |
| --- | --- |
| `issueAgentWorkloadToken` (`POST /api/v1/agent-orchestration/workload/token`) | `private_key_jwt` + DPoP; scope `agent-workload` |
| `readPinnedAgentArtifacts` (`POST /api/v1/agent-orchestration/attempts/{attemptId}/pinned-artifacts`) | Binding check and tool policy at session start |
| The eleven `agentTool*` operations (`POST /api/v1/agent-tools/attempts/{attemptId}/…`) | One request per permitted tool call |

The HTTP client refuses any other path. The server never calls member operations and never sends member or runtime
credentials.

## 4. Logs

Single-line JSON on standard output with only: `event`, `timestamp`, `level`, `attemptId`, `sessionId` (hashed),
`callId`, `toolId`, `origin`, `outcome`, `status`, `durationMs`, and for configuration errors `setting`. Never arguments,
results, problem bodies, links, fencing tokens, access tokens, proofs, keys, or the runtime secret.

## 5. Image

| Property | Value |
| --- | --- |
| Dockerfile | `src/agents/mcp-server/Dockerfile` with `Dockerfile.dockerignore`; build context: repository root |
| Build arguments | `SOCALYTICS_REVISION`, `SOCALYTICS_VERSION` (required, as in the image contract) |
| Labels | `org.opencontainers.image.revision`, `.version`, `.source`, `.title` = `socalytics-mcp-server`, `.description` |
| Base | `python:3.12-slim-bookworm` pinned by digest; no CPU architecture named |
| User | `65532:65532` (numeric, non-root); any orchestrator-assigned non-root UID works |
| Port | 8080 (HTTP) |
| Root filesystem | read-only supported; writable location: tmpfs at `/tmp` (not used by the server) |
| Health probe | none in the image; orchestrators probe `/alive` and `/health` |
| Configuration | environment variables and mounted files only (data model); no stamp, profile, or secret values in the image |
| Lifetime | long-running |
