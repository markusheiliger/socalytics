## Path Conventions

- Platform production code: `src/platform/SocAlytics.Platform.{Domain,Application,Infrastructure,Api,AppHost}/`
- Platform tests: `src/platform/Tests/SocAlytics.Platform.{Integration,Architecture,Host,Contracts}.Tests/`
- Canonical contracts: repository-root `contracts/`
- Recordings code sits in a `Recordings` folder and namespace of each layer; the S3 port lives in `SocAlytics.Platform.Application.Abstractions.ObjectStorage` and its adapter in `SocAlytics.Platform.Infrastructure.ObjectStorage` ([plan.md](plan.md) § Project Structure)
- Application handlers follow the merged Club and Identity convention: a `<Name>Command` (or `<Name>Query`) record plus a public sealed `<Name>Handler` class with `HandleAsync(…, CancellationToken)` returning `OperationResult<T>`, registered as scoped in `AddApplication()`, so the Api endpoints and the Infrastructure expiry worker can call them; Infrastructure implementations stay `internal` and are registered only by the parameterless `AddInfrastructure()` (options bound with `BindConfiguration`; no new parameters).
