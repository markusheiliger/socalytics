# Contract: Queue Credentials

`POST /api/v1/analyst-managers/self/queue-credentials`

This is a Manager-facing operation with Manager machine authentication
(`RequireAnalystManager`, DPoP-bound access token), next to the existing
`self/registration` operations. The shared golden fixtures live in
`contracts/analyst-manager/queue-credentials/v1/` and are validated by
`SocAlytics.Platform.Contracts.Tests` and the Manager's `GoldenFixtureTests`.

## Request

```json
{
  "userPublicKey": "UDXU4RCSJNZOIQHZNWXHXORDPRTGNJAHAHFRGZNEEJCPQTT2M7NLCNF4",
  "capabilities": [ { "id": "player-detection", "version": "1.0.0" } ]
}
```

- `userPublicKey` is required. It is a NATS user NKey public key (prefix `U`,
  base32), generated by the Manager for this credential only. The platform never
  receives a seed.
- `capabilities` is required. It lists the capabilities the Manager's
  validated runtime offers. Unknown capabilities are ignored, not refused, so
  the response lists only consumers that exist.

## Response `201 Created`

```json
{
  "userJwt": "eyJ0eXAiOiJKV1QiLCJhbGciOiJlZDI1NTE5LW5rZXkifQ…",
  "expiresAt": "2026-10-12T14:42:33Z",
  "queueUrl": "nats://localhost:4222",
  "stream": "SOCALYTICS_ANALYSIS_JOBS",
  "consumers": [ { "capability": "player-detection", "consumer": "analyst-player-detection" } ],
  "inboxPrefix": "_INBOX_9f2c1e0a",
  "maxConcurrentAnalysts": 2
}
```

- `userJwt` is signed by the stamp account. Its `sub` is `userPublicKey`, its
  `exp` is `expiresAt`, and its permissions are as in
  [queue-topology-and-permissions.md](queue-topology-and-permissions.md).
- `inboxPrefix` is unique per Manager. The Manager must use it as its client
  inbox prefix.
- `maxConcurrentAnalysts` is the stamp's maximum concurrency per Manager
  (FR-019).

## Refusals

All refusals are problem details (`urn:socalytics:problem:<code>`).

| Status | Code | When |
| --- | --- | --- |
| 400 | `invalid-user-key` | `userPublicKey` missing or not a user NKey public key |
| 400 | `invalid-capabilities` | `capabilities` missing or malformed |
| 401 | (none) | Missing or invalid Manager authentication |
| 403 | `manager-not-active` | Registration is not Active (also after revocation or unregistration) |
| 409 | `user-key-reused` | `userPublicKey` was already issued |

The platform never logs `userJwt` (FR-025).
