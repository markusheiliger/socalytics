**Input**: Design documents from `specs/20261005-130704-analyst-manager-registration/`

**Tests**: Required. The spec demands automated verification of every behavior (FR-035, SC-011) and the constitution requires focused tests. Every task adds the tests for the code it creates in the same task, so the build (warnings are errors) and the full test suites of both solutions stay green after each task. Windows- and macOS-only tests use xUnit v3 `SkipUnless` (or `Assert.SkipUnless`) on `OperatingSystem.IsWindows()` / `OperatingSystem.IsMacOS()` and are reported as skipped on the Linux runner; Windows- and macOS-only production types carry `[SupportedOSPlatform("windows")]` / `[SupportedOSPlatform("macos")]` and every caller guards with `OperatingSystem.Is…()` so the CA1416 platform analyzer raises no warning on Linux.

**Organization**: Tasks are grouped by user story. Merged before this feature starts (do not re-create): the environment feature `specs/20261007-115855-environment-verification-coverage` (SoftHSM2 on the runner; verification of `contracts/` and of `src/analysts/manager/SocAlytics.Analysts.Manager.slnx`), Platform Persistence Foundation (`IUnitOfWork.BeginAsync` → `IUnitOfWorkScope`, `VersionedWriteResult`, `socalytics.attach_version_trigger(regclass)`, the Migrator, `Tests/SocAlytics.Platform.Integration.Tests` with `PostgresContainerFixture`/`IsolatedDatabase` and `Structure/PersistedTableClassifications.cs`), and Club and Identity Foundation (`IRequestContext`, `IAuditTrail` with `RecordAsync`/`RecordIndependentAsync`, `AuditEvent`, `AuditOutcome`, `AuditResource`, `OperationResult<T>`, `OperationFailure`, `IAccessAuthorizer.AuthorizeClubAsync`, `ClubPermission.Register`/`Administer`, scheme `SocAlyticsSession`, `AuthorizationPolicyNames.ActiveMember`, `MapMemberApi`, `SessionAntiforgeryFilter` with `X-CSRF-Token`, `ProblemResults`, tables `member_account`, `club`, `security_audit_event`, the anonymous-endpoint allow list and anti-forgery coverage rule in `Tests/SocAlytics.Platform.Architecture.Tests`, and its integration-test helpers for creating members with roles and signing in), and Recording Lineage and Upload (the repository-root `contracts/README.md` index with columns Artifact, Owner, Version, Example, Validation command; `src/platform/Tests/SocAlytics.Platform.Contracts.Tests` in `SocAlytics.Platform.slnx`, which copies every `contracts/**` file into its output and holds the discovery class `ContractCatalog` (namespace `SocAlytics.Platform.Contracts.Tests`, members `Schemas`, `IndexRows`, `LoadRegistry()`; excludes `**/releases/**`), `ContractIndexTests`, and `SchemaMetaValidationTests`; `JsonSchema.Net` 8.0.5 in `src/platform/Directory.Packages.props`; its own migration).
