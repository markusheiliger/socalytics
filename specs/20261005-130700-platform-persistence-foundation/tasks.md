# Tasks: Platform Persistence Foundation

**Input**: Design documents from `specs/20261005-130700-platform-persistence-foundation/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/ (`readiness.md`, `migrator-cli.md`, `migration-authoring.md`, `persistence-abstractions.md`), quickstart.md

**Tests**: Required. The spec demands automated verification (FR-026, FR-027, FR-028) and the constitution requires focused tests. Every test is written in the same task as the code it verifies, or in a task directly after it that adds passing tests for already implemented code. There are no "failing test first" tasks.

**Organization**: Tasks are grouped by user story. Tasks run strictly in file order, one task per run. After every task, `dotnet restore`, `dotnet build` (warnings are errors), and `dotnet test` of `src/platform/SocAlytics.Platform.slnx` must pass. Docker must be running for Host.Tests and Integration.Tests.

**Canonical names** (from `contracts/persistence-abstractions.md` § Canonical Names; later features consume them, so use them exactly): `IUnitOfWork.BeginAsync` → `IUnitOfWorkScope` (`CommitAsync`, `RollbackAsync`, `DisposeAsync`); internal `IDbSession` (`GetConnectionAsync`, `Transaction`, `RequireTransaction`); `VersionedWriteResult` with `VersionedWriteOutcome` values `Applied`, `NotFound`, `ConcurrencyConflict`; trigger functions `socalytics.advance_version()` and `socalytics.touch_aggregate_root()`; procedures `socalytics.attach_version_trigger(regclass)` and `socalytics.attach_aggregate_child_triggers(regclass, regclass, name, name)`; opt-out setting `socalytics.suppress_version`; manifest `src/platform/Tests/SocAlytics.Platform.Integration.Tests/Structure/PersistedTableClassifications.cs`; projects `SocAlytics.Platform.Migrator` and `SocAlytics.Platform.Integration.Tests`.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependencies on incomplete tasks); informational only, because runs are sequential
- **[Story]**: Which user story this task belongs to (US1, US2, US3)
- Paths are relative to the repository root

## Path Conventions

- Production code: `src/platform/SocAlytics.Platform.*/`
- Tests: `src/platform/Tests/SocAlytics.Platform.*.Tests/`
- Integration test folders in `src/platform/Tests/SocAlytics.Platform.Integration.Tests/`: `Infrastructure/` (fixtures and helpers), `TestMigrations/<Scenario>/` (test-only SQL, sequences `9001+`), `Migrations/`, `Access/`, `Transactions/`, `Concurrency/`, `Structure/`, `Readiness/`
