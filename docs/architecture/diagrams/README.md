# Architecture Diagrams

This directory contains shared diagram sources and rendered assets used by the architecture documentation.

## Conventions

- Keep a diagram source and its rendered output together with the same lowercase kebab-case basename.
- Prefer Mermaid embedded in the document that explains the diagram when practical.
- Reference assets with relative links and descriptive alternative text.
- Update the source and rendered output in the same change.
